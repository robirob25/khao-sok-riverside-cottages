# Khao Sok Riverside Cottages — Official Web Platform

> A luxury eco-resort nestled beside the ancient rainforest of Khao Sok National Park, Southern Thailand.

## 🌿 Overview
- **Framework**: Astro 7 + Tailwind CSS v4
- **Design System**: Silent Luxury & Borgo Egnazia-inspired aesthetic (warm linen `#FAF8F5`, rainforest charcoal `#12281b`, champagne gold `#BA9038`)
- **Responsive**: 100% mobile, tablet, and desktop pixel-perfect responsive layouts
- **Performance**: Sharp-optimized image pipeline, non-blocking typography, zero layout shift (CLS), sub-second LCP
- **Architecture**: 153 static pages with full verbatim content fidelity and native EN/TH bilingual support

## 🚀 Development
```bash
npm install
npm run dev
```
